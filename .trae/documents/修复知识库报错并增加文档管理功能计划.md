## 知识库功能优化与修复方案

针对文件上传后的 Embedding 404 错误、文档删除需求以及手动触发解析的需求，制定以下优化方案。

### 1. 修复 Embedding 404 错误
**原因分析**：目前代码默认尝试从 DeepSeek 或 OpenAI 的 BaseURL 获取 Embedding，但 DeepSeek 并不支持标准向量接口。
**解决方案**：
- **后端**：在 `ConfigSchema.js` 和 `configService.js` 中增加独立的 `embedding` 配置项（API Key, Base URL, Model）。
- **服务层**：更新 `embeddingService.js`，优先读取专用的 Embedding 配置，避免复用不支持该功能的 Provider 地址。
- **配置建议**：建议用户使用阿里云 DashScope 或 OpenAI 的向量模型。

### 2. 新增文档管理功能
**删除功能**：
- **后端**：在 `knowledgeController.js` 中实现删除逻辑：
    - 删除 `KnowledgeDocument` 记录。
    - 删除关联的所有 `KnowledgeChunk` 向量块。
    - 删除磁盘上的物理文件。
    - 更新知识库的统计信息（文档数、片段数）。
**手动解析**：
- **后端**：修改上传逻辑，上传后不再自动触发解析，改为 `pending` 状态。
- **接口**：新增 `POST /:kbId/documents/:docId/process` 接口用于手动触发解析。

### 3. 前端界面升级
- **服务层**：在 `knowledgeService.js` 中补充 `deleteDocument` 和 `processDocument` 接口调用。
- **页面优化** (`KnowledgePage.vue`)：
    - **操作列**：在文档表格中增加“解析”和“删除”按钮。
    - **状态联动**：仅在 `pending` 或 `failed` 状态下显示“解析”按钮。
    - **进度反馈**：点击解析后，实时更新文档状态。

### 4. 系统配置界面适配
- 在“系统配置”页面增加 Embedding 专用配置项，方便用户填写正确的向量服务参数。
