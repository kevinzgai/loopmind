# 智能体嵌入插件（Widget）实施计划

为了实现将智能体作为小助手插件嵌套到第三方网站，我计划按照以下步骤进行开发：

## 1. 前端：开发精简版聊天页面 (AgentWidgetPage)
*   **目标**：创建一个专门用于 iframe 嵌入的页面，去除侧边栏、导航栏等冗余 UI。
*   **功能**：
    *   保留核心对话流和输入框。
    *   针对小窗口（如 400x600）进行响应式布局优化。
    *   支持匿名会话（通过本地存储识别用户）。
*   **路由**：添加新路径 `/agent/:agentId/widget`。

## 2. 静态资源：编写嵌入脚本 (widget.js)
*   **路径**：`frontend/public/widget.js`。
*   **功能**：
    *   在宿主网站右下角自动创建一个“聊天气泡”图标。
    *   点击图标时，动态创建/切换一个 iframe，加载上述的 Widget 页面。
    *   处理简单的展开/收起动画效果。

## 3. 用户界面：添加“嵌入代码”获取功能
*   **修改文件**：[MyAgentsPage.vue](file:///e:/chart-ai/frontend/src/views/agent/MyAgentsPage.vue)。
*   **功能**：
    *   在每个智能体卡片上增加一个“嵌入”按钮。
    *   点击后弹出对话框，提供一段可复制的 `<script>` 代码。
    *   示例代码：`<script src="http://your-domain.com/widget.js" data-agent-id="AGENT_ID"></script>`。

## 4. 后端与安全性 (Backend)
*   **CORS 配置**：确保后端 API 允许跨域请求（当前已配置为 `cors()`，基本满足要求）。
*   **安全策略**：由于需要被 iframe 嵌入，确保没有设置过严的 `X-Frame-Options` 或 `Content-Security-Policy`。

## 5. 关键里程碑
1.  完成 `AgentWidgetPage.vue` 基础布局。
2.  编写并测试 `widget.js` 在外部 HTML 中的运行情况。
3.  在管理后台上线“获取嵌入代码”功能。
