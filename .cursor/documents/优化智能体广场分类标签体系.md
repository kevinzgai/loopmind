## 智能体广场分类标签优化方案

目前智能体的分类标签在前后端均未实现闭环，前端分类是硬编码且未与后端数据关联。本次重构将建立一套标准的分类体系，并打通前后端链路。

### 1. 标准化分类定义
建立统一的分类体系（包含图标）：
- **编程** (💻): 代码辅助、算法、架构设计
- **写作** (✍️): 文案创作、翻译、论文辅助
- **教育** (🎓): 语言学习、学科辅导、知识科普
- **生活** (🏠): 饮食健康、旅行、情感咨询
- **娱乐** (🎮): 游戏角色、同人创作、幽默段子
- **职场** (💼): 面试技巧、简历优化、项目管理
- **创意** (🎨): 灵感生成、艺术设计助手

### 2. 技术实施步骤

#### 后端优化 (Node.js/Mongoose)
1. **Schema 更新**：在 [AgentSchema.js](file:///e:/chart-ai/backend/src/modules/agent/models/AgentSchema.js) 中增加 `category` 字段（String 类型，默认 '生活'）。
2. **Controller 调整**：
   - 更新 `handleCreateAgent`：从请求体中接收 `category`。
   - 更新 `handleGetPublishedAgents`：支持从 Query 中获取 `category` 并传递给 Service。
   - 更新 `handleGenerateAgentConfig`：在 AI 生成逻辑中加入“自动识别分类”的指令。
3. **Service 调整**：更新 `getPublishedAgents`，在查询数据库时增加可选的 `category` 过滤条件。

#### 前端优化 (Vue 3)
1. **配置常量**：创建 `src/constants/agent.js`，定义统一的分类列表供全局使用。
2. **表单增强**：在 [AgentForm.vue](file:///e:/chart-ai/frontend/src/components/agent/AgentForm.vue) 中增加分类选择下拉框，并让“一键生成”功能支持分类自动填充。
3. **广场升级**：
   - 在 [HomePage.vue](file:///e:/chart-ai/frontend/src/views/home/HomePage.vue) 中使用统一常量渲染分类 Tabs。
   - 将分类过滤逻辑从前端纯筛选改为后端 API 过滤（支持大规模数据）。
   - 给分类标签增加对应的 Emoji 图标，提升视觉效果。

#### 数据迁移
- 编写一个简单的脚本或在启动时自动为没有分类的现有智能体设置默认分类（'生活'）。
