## 1. 项目需求文档 (PRD)
### 项目背景
开发一个集成了多模态交互、自定义智能体（Agent）和知识库（RAG）功能的 AI 对话平台。用户可以创建具有特定人格、音色和专业知识的 AI 助手，并支持语音和文字的双向交互。

### 功能需求
*   **用户系统**：支持用户注册、登录及权限管理（普通用户与管理员）。
*   **智能体广场**：展示已发布的智能体，支持分类筛选和搜索。
*   **智能体管理**：用户可创建/编辑智能体，配置模型（DeepSeek等）、人格设定、初始记忆及关联知识库。
*   **知识库 (RAG)**：支持 PDF/Docx 文档上传、自动分片、向量化存储及语义检索，增强智能体的专业知识。
*   **多模态对话**：
    *   **文字交互**：支持流式输出。
    *   **语音交互**：集成阿里云 ASR（语音转文字）和 TTS（文字转语音），支持多种音色。
*   **后台管理**：管理员可配置系统级参数（API Keys、默认模型等）。

## 2. 技术开发文档
### 技术栈
*   **前端**：Vue 3 + Vite + Tailwind CSS + Radix Vue (Shadcn-like)。
*   **后端**：Node.js + Express + Mongoose。
*   **数据库**：MongoDB（存储用户、智能体、聊天记录、知识库元数据）。
*   **AI 服务**：
    *   **大模型**：DeepSeek (API)。
    *   **向量化/搜索**：DeepSeek Embedding 或同类服务，结合本地向量检索逻辑。
    *   **语音服务**：阿里云 ASR/TTS。

### 核心架构
*   **模块化设计**：后端采用模块化结构（Agent 模块、Knowledge 模块、Auth 模块等）。
*   **RAG 流程**：文档上传 -> 解析分片 -> Embedding 向量化 -> 存储至 MongoDB -> 对话时语义检索 -> 注入上下文 -> 大模型生成。
*   **实时交互**：采用 SSE (Server-Sent Events) 实现大模型流式响应。

## 3. 实施方案文档
### 实施步骤
1.  **环境准备**：
    *   部署 MongoDB 实例。
    *   配置 `.env` 文件（包含 DeepSeek、阿里云等 API 密钥）。
2.  **开发阶段**：
    *   **第一阶段**：完成基础认证系统及单体 AI 对话功能。
    *   **第二阶段**：实现智能体创建及持久化配置。
    *   **第三阶段**：集成知识库（RAG）功能，实现向量搜索。
    *   **第四阶段**：集成 ASR/TTS 语音交互功能。
3.  **测试与优化**：
    *   进行压力测试及 RAG 准确率调优。
    *   前端 UI/UX 响应式适配。
4.  **部署上线**：
    *   建议使用 Docker 容器化部署前端及后端服务。
