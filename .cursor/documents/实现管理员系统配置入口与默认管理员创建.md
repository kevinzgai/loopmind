**目标与范围**
- 新增管理员系统配置入口页面，仅管理员可访问
- 支持模型与相关服务配置（DeepSeek、Qwen、默认提供商、ASR/TTS 等）
- 创建默认管理员账号：username=admin，email=admin@123（使用密码：admin@123）

**后端改动**
- 用户角色
  - 修改 UserSchema 增加 role（enum: user|admin，默认 user）
  - 登录/注册/验证接口返回 role
- 管理员鉴权
  - 新增 authorizeAdmin 中间件：authenticateToken 后校验用户 role === 'admin'
- 系统配置存储
  - 新增 ConfigSchema：provider、DeepSeek/Qwen 的 API Key/BaseURL/Model、ASR/TTS 配置
  - 新增 configService：getConfig（遮盖敏感）、updateConfig（仅管理员，校验并保存）
  - aiService 优先读取数据库配置（内存缓存），无则回退 .env
- 管理接口
  - 新增 /api/admin/config：GET（返回配置，遮盖敏感）、PUT（更新配置，管理员专用）
- 默认管理员
  - 在 server.js 连接数据库成功后执行 bootstrapAdmin：若不存在管理员用户则创建默认管理员（admin / admin@123），并避免日志泄露密码

**前端改动**
- 认证状态
  - authStore 增加 role 与 isAdmin 计算属性；登录后存储 role
- 路由与守卫
  - 新增 /admin/system 页面路由
  - 路由守卫：仅 isAdmin 可进入，否则重定向首页/403
- 页面实现
  - AdminSystemPage.vue：配置表单（默认提供商、DeepSeek/Qwen 的 API Key/BaseURL/Model、ASR/TTS）
  - 交互：加载 GET /api/admin/config；保存 PUT /api/admin/config；敏感字段提供显示/隐藏；错误与成功提示

**安全与合规**
- 后端响应的敏感字段（API Key）用遮盖显示，不回传明文；日志不打印敏感信息
- 所有 /api/admin/* 接口必须 authenticateToken + authorizeAdmin

**数据与环境变量**
- 可新增 ADMIN_USERNAME、ADMIN_EMAIL、ADMIN_PASSWORD；若未设置则仅在开发环境创建默认管理员

**实施步骤**
1) 修改后端模型与认证服务，加入 role 字段与返回值
2) 增加 authorizeAdmin 中间件与 /api/admin/config 路由与服务
3) aiService 支持从数据库配置读取与缓存
4) 在 server.js 中加入 bootstrapAdmin 创建默认管理员
5) 前端增加 admin 页面、路由守卫、配置表单与 API 调用
6) 联调与验证：
   - 使用默认管理员登录，访问 /admin/system 能加载与更新配置
   - 普通用户不可见或被拒绝访问
   - 更新后 AI 服务按新配置工作
