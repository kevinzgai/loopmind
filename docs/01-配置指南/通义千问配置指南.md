# 通义千问 AI 配置指南

## 📝 概述

本指南将帮助你配置通义千问（Qwen）AI 服务，实现多模型支持。

## 🔑 获取 API Key

### 1. 注册阿里云账号

访问 [阿里云官网](https://www.aliyun.com/) 注册账号。

### 2. 开通通义千问服务

1. 访问 [通义千问控制台](https://dashscope.console.aliyun.com/)
2. 点击「开通服务」
3. 选择合适的套餐（有免费额度）

### 3. 获取 API Key

1. 在控制台点击「API-KEY 管理」
2. 点击「创建新的 API-KEY」
3. 复制生成的 API Key

## ⚙️ 配置步骤

### 1. 配置环境变量

编辑 `backend/.env` 文件，添加通义千问配置：

```env
# 通义千问 AI 配置
QWEN_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxx
QWEN_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
QWEN_MODEL=qwen-turbo

# 默认 AI 服务（deepseek 或 qwen）
DEFAULT_AI_PROVIDER=deepseek
```

### 2. 可用模型

通义千问提供多个模型，你可以根据需求选择：

| 模型名称 | 说明 | 适用场景 |
|---------|------|---------|
| `qwen-turbo` | 快速响应 | 日常对话、快速问答 |
| `qwen-plus` | 平衡性能 | 复杂任务、代码生成 |
| `qwen-max` | 最强性能 | 专业任务、深度分析 |
| `qwen-long` | 长文本 | 长文档处理 |

修改 `QWEN_MODEL` 环境变量即可切换模型。

### 3. 重启服务

配置完成后，重启后端服务：

```bash
cd backend
npm start
```

## 🎯 使用方法

### 前端切换模型

1. 打开 AI 对话页面 (`http://localhost:5173/chat`)
2. 在页面右上角找到「AI 模型」选择器
3. 选择「通义千问 (qwen-turbo)」
4. 开始对话

### 设置默认模型

修改 `.env` 文件中的 `DEFAULT_AI_PROVIDER`：

```env
# 使用通义千问作为默认模型
DEFAULT_AI_PROVIDER=qwen

# 或使用 DeepSeek 作为默认模型
DEFAULT_AI_PROVIDER=deepseek
```

## 🔄 多模型支持

系统支持同时配置多个 AI 模型：

- **DeepSeek**: 专注于代码和技术问题
- **通义千问**: 中文理解能力强，适合日常对话

用户可以在前端随时切换，每个模型的对话历史独立保存。

## 💡 注意事项

1. **API Key 安全**: 不要将 API Key 提交到代码仓库
2. **费用控制**: 注意 API 调用次数和费用
3. **模型选择**: 根据任务选择合适的模型
4. **对话历史**: 不同模型的对话历史是独立的

## 🐛 常见问题

### 1. API Key 无效

**问题**: 提示 API Key 无效

**解决**:
- 检查 API Key 是否正确复制
- 确认 API Key 是否已激活
- 检查账号是否已开通服务

### 2. 请求失败

**问题**: 请求返回错误

**解决**:
- 检查网络连接
- 确认账号余额充足
- 查看控制台错误日志

### 3. 模型不可用

**问题**: 选择的模型无法使用

**解决**:
- 确认模型名称正确
- 检查账号是否有权限使用该模型
- 尝试使用其他模型
