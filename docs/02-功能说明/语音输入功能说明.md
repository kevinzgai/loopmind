# 语音输入功能说明

## 📝 概述

AI 对话页面现在支持语音输入功能，用户可以通过语音快速输入消息，无需手动打字。

## 🎤 功能特点

### 1. 实时语音识别
- 使用阿里云 ASR 流式识别服务
- 边说边识别，延迟 < 1 秒
- 自动添加标点符号
- 支持中文普通话

### 2. 混合输入模式
- **文字输入**：传统键盘输入
- **语音输入**：按住麦克风按钮说话
- **组合使用**：可以先打字，再语音补充，或反之

### 3. 智能文本合并
- 语音识别结果自动追加到输入框
- 自动添加空格分隔
- 保留原有文本内容

## 🎯 使用方法

### 基本操作

1. **打开 AI 对话页面**
   - 访问 `http://localhost:5173/chat`

2. **使用语音输入**
   - 找到输入框右侧的麦克风按钮 🎤
   - **按住**麦克风按钮
   - 开始说话
   - **松开**按钮结束录音
   - 等待识别结果自动填入输入框

3. **发送消息**
   - 点击发送按钮或按 Enter 键
   - AI 会根据你的输入（文字或语音）进行回复

### 高级技巧

#### 1. 组合输入
```
场景：想说 "帮我写一个 Python 函数"

方式 1：全部语音
- 按住麦克风说："帮我写一个 Python 函数"

方式 2：混合输入
- 先打字："帮我写一个"
- 再按住麦克风说："Python 函数"
- 结果："帮我写一个 Python 函数"
```

#### 2. 多次语音输入
```
可以多次使用语音输入，每次识别结果会自动追加：

第一次：按住说 "今天天气真好"
第二次：按住说 "适合出去走走"
结果："今天天气真好 适合出去走走"
```

#### 3. 修正和编辑
```
语音识别后，可以：
- 手动编辑识别结果
- 删除错误的部分
- 继续添加内容
```

## ⚙️ 技术细节

### 音频参数
- **采样率**: 16000 Hz
- **声道**: 单声道
- **格式**: 16-bit PCM
- **降噪**: 开启
- **回声消除**: 开启
- **自动增益**: 开启

### 识别特点
- **实时性**: 边说边识别
- **准确率**: 高（阿里云 ASR）
- **延迟**: < 1 秒
- **标点**: 自动添加
- **数字**: 自动转换

## 🐛 常见问题

### 1. 麦克风无法访问

**问题**: 点击麦克风按钮没有反应

**解决方法**:
- 检查浏览器是否允许麦克风权限
- 在浏览器地址栏左侧点击锁图标
- 确保麦克风权限设置为"允许"
- 刷新页面重试

### 2. 识别不准确

**问题**: 语音识别结果不正确

**解决方法**:
- 说话清晰，语速适中
- 避免环境噪音
- 靠近麦克风
- 使用标准普通话
- 检查麦克风质量

### 3. 连接失败

**问题**: 显示"连接失败"

**解决方法**:
- 确认后端服务正在运行
- 检查 WebSocket 连接（ws://localhost:3000/ws-asr-stream）
- 查看浏览器控制台错误信息
- 重启后端服务

### 4. 识别结果未添加

**问题**: 说完话但输入框没有内容

**解决方法**:
- 确保说话时间足够长（至少 1 秒）
- 检查是否有识别结果返回（查看控制台）
- 尝试说更清晰的内容
- 检查网络连接

## 🔒 隐私说明

### 数据处理
- 语音数据通过 WebSocket 实时传输到后端
- 后端转发到阿里云 ASR 服务进行识别
- 识别完成后立即返回结果
- 不保存语音数据

### 安全性
- 使用 HTTPS/WSS 加密传输（生产环境）
- 仅在用户按住按钮时录音
- 松开按钮立即停止录音
- 用户完全控制录音过程

## 📊 性能优化

### 1. 音频处理
- 使用 Web Audio API 直接生成 PCM
- 避免不必要的格式转换
- 实时流式传输，无需缓存

### 2. 网络优化
- WebSocket 长连接，减少握手开销
- 二进制数据传输，减少带宽
- 自动重连机制

### 3. 用户体验
- 即时反馈，无等待感
- 平滑动画过渡
- 清晰的状态提示

## 🎯 最佳实践

### 1. 录音技巧
- **清晰发音**: 吐字清楚，语速适中
- **避免噪音**: 在安静环境使用
- **完整句子**: 说完整的句子，不要断断续续
- **适当停顿**: 句子之间稍作停顿

### 2. 使用建议
- **短句优先**: 每次说一个短句，识别更准确
- **及时检查**: 识别后检查结果，必要时手动修正
- **组合使用**: 文字和语音结合，效率更高
- **熟能生巧**: 多次使用后会更加熟练

### 3. 场景选择
- **适合语音**: 长文本、描述性内容、快速输入
- **适合文字**: 代码、专业术语、精确表达
- **混合使用**: 大部分场景都可以灵活组合
