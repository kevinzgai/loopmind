## 🔧 技术实现

### 1. 路由配置
```javascript
// frontend/src/router/index.js
import { createRouter, createWebHistory } from 'vue-router'

const routes = [
  {
    path: '/',
    name: 'Home',
    component: HomePage,
    meta: { title: '首页' }
  },
  // ... 其他路由
]

const router = createRouter({
  history: createWebHistory(),
  routes
})
```

### 2. 懒加载
```javascript
// 使用动态导入实现懒加载
const ChatPage = () => import('../views/ChatPage.vue')
```

### 3. 路由守卫
```javascript
// 自动更新页面标题
router.beforeEach((to, from, next) => {
  document.title = to.meta.title ? `${to.meta.title} - AI Chat` : 'AI Chat Application'
  next()
})
```

### 4. 主应用更新
```javascript
// frontend/src/main.js
import router from './router'

const app = createApp(App)
app.use(router)  // 注册路由
```

### 5. App.vue 简化
```vue
<template>
  <div id="app">
    <router-view />  <!-- 路由视图 -->
  </div>
</template>
```

## 🎯 使用方式

### 1. 编程式导航
```javascript
import { useRouter } from 'vue-router'

const router = useRouter()

// 跳转到聊天页面
router.push('/chat')

// 跳转到首页
router.push('/')

// 返回上一页
router.back()
```

### 2. 声明式导航
```vue
<template>
  <!-- 使用 router-link -->
  <router-link to="/chat">进入聊天</router-link>
  
  <!-- 命名路由 -->
  <router-link :to="{ name: 'Chat' }">进入聊天</router-link>
  
  <!-- 带参数 -->
  <router-link :to="{ name: 'Chat', params: { id: 123 } }">
    进入聊天
  </router-link>
</template>
```

### 3. 获取路由信息
```javascript
import { useRoute } from 'vue-router'

const route = useRoute()

// 当前路径
console.log(route.path)

// 路由参数
console.log(route.params)

// 查询参数
console.log(route.query)
```

## 📝 开发建议

### 1. 添加新页面
```javascript
// 1. 创建页面组件
// frontend/src/views/NewPage.vue

// 2. 在路由配置中添加
{
  path: '/new-page',
  name: 'NewPage',
  component: () => import('../views/NewPage.vue'),
  meta: { title: '新页面' }
}

// 3. 在首页添加导航卡片
<router-link to="/new-page" class="feature-card">
  <!-- 卡片内容 -->
</router-link>
```

### 2. 添加路由参数
```javascript
// 路由定义
{
  path: '/chat/:id',
  name: 'ChatDetail',
  component: ChatPage
}

// 跳转
router.push({ name: 'ChatDetail', params: { id: 123 } })

// 获取参数
const route = useRoute()
const id = route.params.id
```

### 3. 路由守卫
```javascript
// 全局守卫
router.beforeEach((to, from, next) => {
  // 权限检查
  if (to.meta.requiresAuth && !isAuthenticated()) {
    next('/login')
  } else {
    next()
  }
})

// 组件内守卫
export default {
  beforeRouteEnter(to, from, next) {
    // 进入前
  },
  beforeRouteLeave(to, from, next) {
    // 离开前
  }
}
```

## 🐛 常见问题

### 1. 页面刷新 404
**原因：** 使用 HTML5 History 模式，需要服务器配置

**解决：** 配置服务器将所有路由指向 index.html

```javascript
// Vite 开发服务器已自动配置
// 生产环境需要 Nginx 配置
location / {
  try_files $uri $uri/ /index.html;
}
```

### 2. 路由不生效
**检查：**
- ✅ 是否在 main.js 中注册路由
- ✅ 是否使用 `<router-view />`
- ✅ 路由路径是否正确

### 3. 样式冲突
**解决：**
- 使用 `scoped` 样式
- 使用 CSS Modules
- 使用唯一的类名前缀
