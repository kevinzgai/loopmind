# 🚀 快速开始指南

## 📋 前置要求

- Node.js >= 16.0.0
- npm >= 8.0.0
- 现代浏览器（Chrome、Firefox、Edge、Safari）

## 🔧 安装步骤

### 1. 获取项目代码

```bash
git clone <repository-url>
cd aichat
```

### 2. 配置环境变量

#### 复制配置文件

```bash
# 根目录
cp .env.example .env

# 后端目录
cp .env.example backend/.env
```

#### 填写配置

编辑 `.env` 和 `backend/.env` 文件，填入以下配置：

**必需配置：**

```env
# DeepSeek API Key（必需）
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxx

# 阿里云语音服务（必需）
ALI_TTS_ACCESS_KEY_ID=LTAI5xxxxxxxxxxxxx
ALI_TTS_ACCESS_KEY_SECRET=xxxxxxxxxxxxxxxxxx
ALI_TTS_APP_KEY=xxxxxxxxxxxxxxxxxx
```

**可选配置：**

```env
# 通义千问（可选，如需使用通义千问模型）
QWEN_API_KEY=sk-xxxxxxxxxxxxx
```

### 3. 安装依赖

#### 方式一：一键安装（推荐）

在项目根目录运行：

```bash
npm run install:all
```

#### 方式二：分别安装

```bash
# 安装后端依赖
cd backend
npm install

# 安装前端依赖
cd ../frontend
npm install
```

### 4. 启动服务

#### 方式一：同时启动前后端（推荐）

在项目根目录运行：

```bash
npm run dev
```

这会同时启动：
- 后端服务：http://localhost:3000
- 前端服务：http://localhost:5173

#### 方式二：分别启动

**启动后端：**
```bash
cd backend
npm run dev
```

**启动前端：**
```bash
cd frontend
npm run dev
```

### 5. 访问应用

打开浏览器访问：http://localhost:5173

## 🎯 首次使用

### 1. 测试 AI 对话

1. 点击首页的"AI 对话"卡片
2. 在输入框输入消息，按回车发送
3. 查看 AI 的流式回复

### 2. 测试语音输入

1. 在对话页面，点击右侧的麦克风图标
2. 长按语音按钮开始录音
3. 松手后自动识别并发送

### 3. 测试语音播报

1. 点击右上角的喇叭图标开启语音播报
2. 发送消息后，AI 回复会自动朗读

### 4. 测试流式 TTS

1. 返回首页，点击"文字转语音 TTS"
2. 切换到"流式 TTS"标签
3. 点击"建立连接"
4. 输入文字，点击"开始合成"

## ❌ 常见问题

### 问题 1：端口被占用

**错误信息：**
```
Error: listen EADDRINUSE: address already in use :::3000
```

**解决方案：**
1. 修改 `backend/.env` 中的 `PORT` 为其他端口
2. 或者关闭占用端口的程序

### 问题 2：依赖安装失败

**解决方案：**
```bash
# 清除缓存
npm cache clean --force

# 删除 node_modules
rm -rf backend/node_modules frontend/node_modules

# 重新安装
npm run install:all
```

### 问题 3：API Key 无效

**错误信息：**
```
401 Authentication Fails
```

**解决方案：**
1. 检查 `.env` 文件中的 API Key 是否正确
2. 确认 API Key 没有过期
3. 检查是否有多余的空格或换行

### 问题 4：麦克风权限被拒绝

**解决方案：**
1. 浏览器地址栏左侧点击锁图标
2. 允许麦克风权限
3. 刷新页面

### 问题 5：语音服务不可用

**错误信息：**
```
阿里云 TTS 配置不完整
```

**解决方案：**
1. 检查阿里云配置是否填写完整
2. 确认阿里云服务已开通
3. 检查 AccessKey 权限
