# 阿里云百炼 - 语言大模型定制语料

## 什么是语料？

语料是用于训练 AI 模型的对话示例数据集，格式为 JSONL（每行一个 JSON 对象）。

## 语料格式

```json
{"messages": [{"role": "system", "content": "你是助手"}, {"role": "user", "content": "你好"}, {"role": "assistant", "content": "你好！有什么可以帮你？"}]}
```

### 三段式结构
1. **system** - 系统指令（人设、角色、行为准则）
2. **user** - 用户输入  
3. **assistant** - AI 回复（期望的理想回答）

## 语料规范

- 人设一致：system 指令保持一致
- 对话自然：有语气词、表情
- 多样化：不同难度、场景
- 数量建议：50-200 条

## 使用步骤

1. 保存为 .jsonl 文件
2. 上传阿里云百炼平台
3. 选择基础模型（如 Qwen）
4. 提交微调训练
5. 测试验证效果
