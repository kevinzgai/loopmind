```sql
CREATE TABLE users (
```

```sql
CREATE TABLE conversations (

  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
```

```sql
CREATE TABLE messages (
  id VARCHAR(36) PRIMARY KEY,
  conversation_id VARCHAR(36) NOT NULL,
  role ENUM('system', 'user', 'assistant') NOT NULL,
  content TEXT NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (conversation_id) REFERENCES conversations(id),
  INDEX idx_conversation (conversation_id, created_at)
);
```

#### 7.1.2 请求优化
```javascript
// TTS 请求队列
const MAX_CONCURRENT_TTS = 1;
let activeTTSRequests = 0;
let ttsRequestQueue = [];

async function processTTSQueue() {
  while (ttsRequestQueue.length > 0 && 
         activeTTSRequests < MAX_CONCURRENT_TTS) {
    const task = ttsRequestQueue.shift();
    activeTTSRequests++;
    await task();
    activeTTSRequests--;
  }
}
```

#### 7.1.3 音频优化
```javascript
// 音频队列管理
let audioQueue = [];
let isPlayingQueue = false;

async function playAudioQueue() {
  if (isPlayingQueue) return;
  isPlayingQueue = true;
  
  while (audioQueue.length > 0) {
    const audio = audioQueue.shift();
    await playAudio(audio);
  }
  
  isPlayingQueue = false;
}
```

## 8. 错误处理

### 8.1 错误分类

```javascript
// 客户端错误（4xx）
- 400 Bad Request: 参数错误
- 401 Unauthorized: 认证失败
- 403 Forbidden: 权限不足
- 404 Not Found: 资源不存在
- 429 Too Many Requests: 请求过多

// 服务端错误（5xx）
- 500 Internal Server Error: 服务器错误
- 502 Bad Gateway: 网关错误
- 503 Service Unavailable: 服务不可用
```

### 8.2 错误处理策略

```javascript
// 前端错误处理
```

## 11. 监控与日志

### 11.1 日志系统

```javascript
// 日志级别
const LOG_LEVELS = {
  ERROR: '❌',
  WARN: '⚠️',
  INFO: 'ℹ️',
  SUCCESS: '✅',
  DEBUG: '🔍'
};

// 日志函数
function log(level, message, data) {
  const timestamp = new Date().toISOString();
  console.log(`${LOG_LEVELS[level]} [${timestamp}] ${message}`, data || '');
}
```

### 11.2 性能监控

```javascript
// 请求耗时监控
app.use((req, res, next) => {
  const start = Date.now();
  res.on('finish', () => {
    const duration = Date.now() - start;
    log('INFO', `${req.method} ${req.path} - ${duration}ms`);
  });
  next();
});
```
