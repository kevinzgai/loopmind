## 🎯 主要功能

### 1. AI 对话

- 多模型支持（DeepSeek + 通义千问）
- 前端模型切换
- 流式响应
- 上下文记忆
- 独立对话历史
- **语音输入**：按住麦克风说话，实时识别

### 2. 文字转语音 (TTS)
- 阿里云 TTS 服务
- 150+ 种音色
- 11 个场景分类
- 语速调节
- 音频播放和下载

### 3. 语音识别 (ASR)
- **普通模式**: 录音完成后识别，3-5秒延迟
- **流式模式**: 边说边识别，<1秒延迟
- 自动标点和数字转换
- 支持文件上传

## 🛠️ 技术栈

### 前端
- Vue 3 + Vite
- TypeScript
- Tailwind CSS
- Vue Router

### 后端
- Node.js + Express
- WebSocket (ws)
- 阿里云智能语音服务
- FFmpeg (音频处理)
