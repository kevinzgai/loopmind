# 前端认证集成指南

## 概述

本文档介绍前端认证系统的实现，包括登录、注册、路由保护等功能。

## 文件结构

```
frontend/src/
├── stores/
│   └── authStore.js          # 认证状态管理
├── views/
│   ├── LoginPage.vue         # 登录页面
│   ├── RegisterPage.vue      # 注册页面
│   ├── HomePage.vue          # 首页（已更新）
│   └── ChatPage.vue          # 对话页面（已更新）
├── router/
│   └── index.js              # 路由配置（已更新）
└── App.vue                   # 主应用组件（已更新）
```

## 核心功能

### 1. 认证状态管理 (authStore.js)

使用 Vue 3 Composition API 管理认证状态：

```javascript
// 导出的状态
export const user              // 当前用户信息
export const token             // JWT Token
export const isLoading         // 加载状态
export const error             // 错误信息

// 导出的计算属性
export const isAuthenticated   // 是否已认证
export const currentUser       // 当前用户

// 导出的方法
export async function register(username, email, password, confirmPassword)
export async function login(username, password)
export async function logout()
export async function getCurrentUser()
export async function refreshToken()
export function initializeAuth()
```

### 2. 登录页面 (LoginPage.vue)

- 用户名和密码输入
- 表单验证
- 错误提示
- 加载状态
- 注册链接

### 3. 注册页面 (RegisterPage.vue)

- 用户名、邮箱、密码输入
- 密码确认
- 表单验证
- 错误提示
- 登录链接

### 4. 路由保护

在 `router/index.js` 中配置：

```javascript
// 需要认证的路由
{
  path: '/chat',
  component: ChatPage,
  meta: {
    requiresAuth: true
  }
}

// 路由守卫
router.beforeEach((to, from, next) => {
  if (to.meta.requiresAuth && !token.value) {
    next('/login')
  } else {
    next()
  }
})
```

### 5. 导航栏 (App.vue)

- 显示当前用户名
- 登出按钮
- 导航链接
- 仅在已认证时显示

### 6. 首页更新 (HomePage.vue)

- 未登录时显示登录/注册按钮
- 已登录时隐藏认证按钮
- 导航栏显示用户信息

## 使用流程

### 1. 初始化认证

在应用启动时，`App.vue` 会调用 `initializeAuth()` 从本地存储恢复认证状态：

```javascript
onMounted(() => {
  initializeAuth()
})
```

### 2. 用户注册

```javascript
import { register } from '@/stores/authStore.js'

await register(username, email, password, confirmPassword)
// 注册成功后跳转到登录页
```

### 3. 用户登录

```javascript
import { login } from '@/stores/authStore.js'

await login(username, password)
// 登录成功后跳转到首页
```

### 4. 访问受保护的路由

- 未登录时自动重定向到登录页
- 登录后可以访问受保护的路由

### 5. 用户登出

```javascript
import { logout } from '@/stores/authStore.js'

await logout()
// 登出后跳转到登录页
```

## API 端点

### 注册
- **URL**: `POST /api/auth/register`
- **请求体**:
  ```json
  {
    "username": "string",
    "email": "string",
    "password": "string",
    "confirmPassword": "string"
  }
  ```
- **响应**: `{ user: {...}, token: "..." }`

### 登录
- **URL**: `POST /api/auth/login`
- **请求体**:
  ```json
  {
    "username": "string",
    "password": "string"
  }
  ```
- **响应**: `{ user: {...}, token: "..." }`

### 获取当前用户
- **URL**: `GET /api/auth/me`
- **认证**: 需要 Bearer Token
- **响应**: `{ user: {...} }`

### 登出
- **URL**: `POST /api/auth/logout`
- **认证**: 需要 Bearer Token
- **响应**: `{ message: "..." }`

### 刷新 Token
- **URL**: `POST /api/auth/refresh`
- **认证**: 需要 Bearer Token
- **响应**: `{ token: "..." }`

## 本地存储

认证信息存储在浏览器本地存储中：

```javascript
localStorage.getItem('token')    // JWT Token
localStorage.getItem('user')     // 用户信息 (JSON)
```

## 错误处理

所有认证方法都会设置 `error` 状态，可以在组件中访问：

```javascript
import { error } from '@/stores/authStore.js'

// 在模板中显示错误
<div v-if="error" class="error-message">{{ error }}</div>
```

## 常见问题

### Q: 登录后页面没有更新？
A: 确保在 `App.vue` 中调用了 `initializeAuth()`，并且路由器正确配置了守卫。

### Q: Token 过期后怎么办？
A: 可以调用 `refreshToken()` 方法刷新 Token，或者让用户重新登录。

### Q: 如何添加更多认证字段？
A: 修改后端的 `authController.js` 和前端的 `LoginPage.vue`/`RegisterPage.vue`。
