# 阿里云 TTS 音色列表更新说明

## ✅ 更新完成

已根据阿里云官方文档更新了完整的音色列表，共计 **150+ 种音色**。

## 📊 更新内容

### 1. 后端服务更新
文件：`backend/src/services/aliTtsService.js`

- 更新了 `getSupportedVoices()` 函数
- 包含所有音色的详细信息（名称、类型、场景、品质）
- 按场景分类组织

### 2. 前端数据文件
新建文件：`frontend/src/data/voices.js`

- 创建了独立的音色数据文件
- 按场景分类（11个分类）
- 提供辅助函数：
  - `getAllVoices()` - 获取所有音色
  - `getVoiceById(id)` - 根据ID查找音色
  - `getRecommendedVoices()` - 获取推荐音色

### 3. 前端组件更新
文件：`frontend/src/components/TtsTestDemo.vue`

- 导入新的音色数据
- 使用分组选择器（optgroup）
- 显示音色类型和品质等级

## 🌟 品质等级说明

- **lite 版**：基础版本，适合快速测试
- **标准版**：标准品质，适合大多数场景
- **精品版**：高品质，适合专业场景（文学、超高清等）

## 📝 使用示例

### 后端 API 调用
```javascript
POST /tts
{
  "text": "你好，欢迎使用阿里云语音合成",
  "voice": "zhiqi",  // 知琪 - 温柔女声（精品）
  "speechRate": 0,
  "volume": 50
}
```

### 前端使用
```javascript
import { voiceCategories, getVoiceById } from '../data/voices.js'

// 获取所有分类
const categories = voiceCategories

// 查找特定音色
const voice = getVoiceById('zhiqi')
console.log(voice)
// { id: 'zhiqi', name: '知琪', type: '温柔女声', quality: '精品' }
```
