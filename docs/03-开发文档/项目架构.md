## 🎯 核心模块

### 前端模块

#### 1. 页面组件 (Views)

**ChatPage.vue** - AI 对话页面
- 功能：AI 对话、语音输入、语音播报
- 状态管理：消息列表、加载状态、TTS 状态
- 通信：HTTP（AI 对话）、WebSocket（语音识别）

**HomePage.vue** - 首页导航
- 功能：功能入口、项目介绍
- 路由：导航到各功能页面

**TtsTestPage.vue** - TTS 测试页面
- 功能：普通 TTS、流式 TTS 测试
- 组件：TtsTestDemo、TtsStreamDemo

#### 2. 功能组件 (Components)

**VoiceInput.vue** - 语音输入组件
- 功能：文字/语音模式切换、长按录音
- WebSocket：实时语音识别
- 事件：submit、autoSubmit

**TtsStreamDemo.vue** - 流式 TTS 测试
- 功能：WebSocket 连接、音频流播放
- 音频处理：Web Audio API

#### 3. UI 组件库 (ai-elements)

- Conversation：对话容器
- Message：消息气泡
- Loader：加载动画

### 后端模块

#### 1. 路由层 (Routes)

```javascript
// chatRoutes.js
POST   /api/chat              // AI 对话（流式）
GET    /api/chat/providers    // 获取 AI 提供商列表

// ttsRoutes.js
POST   /api/tts               // 文字转语音

// voiceRoutes.js
POST   /api/asr               // 语音识别（文件）
```

#### 2. 控制器层 (Controllers)

**chatController.js**
- handleChatMessage：处理 AI 对话请求
- getProviders：返回可用的 AI 提供商

**ttsController.js**
- handleTextToSpeech：处理 TTS 请求

**asrController.js**
- handleSpeechToText：处理 ASR 请求

#### 3. 服务层 (Services)

**aiService.js** - AI 服务
```javascript
// 功能
- 管理多个 AI 提供商（DeepSeek、通义千问）
- 对话历史管理（按用户和提供商分离）
- 流式响应处理

// 核心方法
- getConversationHistory(userId, provider)
- addMessageToHistory(userId, message, provider)
- callAIStream(conversationHistory, provider)
- getAvailableProviders()
```

**aliAsrStreamService.js** - 流式语音识别
```javascript
// 功能
- WebSocket 连接管理
- 音频流处理
- 实时识别结果返回

// 核心方法
- handleStreamConnection(ws)
```

**aliTtsService.js** - 语音合成
```javascript
// 功能
- 文字转语音（RESTful API）
- 支持 150+ 音色
- 参数配置（语速、音量等）

// 核心方法
- textToSpeech(text, options)
- getSupportedVoices()
```

**aliTtsStreamService.js** - 流式语音合成
```javascript
// 功能
- WebSocket 连接管理
- 流式音频生成
- 实时音频流返回

// 核心方法
- createTTSStream(options)
- sendTextWithStart(ws, text, appKey, options)
- sendComplete(ws, appKey)
```

**aliTokenService.js** - Token 管理
```javascript
// 功能
- 阿里云 Token 获取
- Token 缓存管理
- 自动刷新

// 核心方法
- getToken()
- clearToken()
```

#### 4. WebSocket 服务 (server.js)

```javascript
// WebSocket 路由
ws://localhost:3000/ws-asr-stream    // 流式语音识别
ws://localhost:3000/ws-tts-stream    // 流式语音合成

// 连接处理
- handleTTSStreamConnection(ws, req)
- handleStreamConnection(ws)  // ASR
```

## 🔄 数据流

### AI 对话流程

```
用户输入
  │
  ▼
前端 ChatPage
  │
  ▼ POST /api/chat
后端 chatController
  │
  ▼
aiService.callAIStream()
  │
  ▼
DeepSeek/通义千问 API
  │
  ▼ 流式响应
前端接收并显示
  │
  ▼ (如果开启 TTS)
TTS 队列处理
  │
  ▼
音频播放
```

### 语音输入流程

```
用户长按录音
  │
  ▼
VoiceInput 组件
  │
  ▼ WebSocket 连接
后端 ws-asr-stream
  │
  ▼ 音频流
aliAsrStreamService
  │
  ▼
阿里云 ASR API
  │
  ▼ 识别结果
前端显示并自动发送
  │
  ▼
AI 对话流程
```

### 流式 TTS 流程

```
用户输入文本
  │
  ▼
TtsStreamDemo 组件
  │
  ▼ WebSocket 连接
后端 ws-tts-stream
  │
  ▼ 文本消息
aliTtsStreamService
  │
  ▼
阿里云 TTS API
  │
  ▼ 音频流
前端 Web Audio API
  │
  ▼
实时播放
```
