## 🌐 API 接口

### TTS 接口

**POST /tts**
```json
{
  "text": "你好，欢迎使用阿里云语音合成",
  "voice": "zhiqi",
  "speechRate": 0,
  "volume": 50,
  "pitchRate": 0
}
```

**响应：** MP3 音频流

### ASR 接口

**POST /asr**

方式1：文件上传
```bash
FormData:
- audio: 音频文件
- format: wav/mp3/webm
- sampleRate: 16000
```

方式2：Base64
```json
{
  "audio": "data:audio/webm;base64,...",
  "format": "webm",
  "sampleRate": 16000
}
```

**响应：**
```json
{
  "success": true,
  "text": "识别的文本内容",
  "timestamp": "2026-01-07T10:30:00.000Z"
}
```

## 📝 使用流程

### TTS 使用流程

1. 用户输入文字
2. 选择音色和参数
3. 点击「转换为语音」
4. 后端获取 Token
5. 调用阿里云 TTS API
6. 返回 MP3 音频
7. 前端播放音频

### ASR 使用流程

1. 用户点击「开始录音」或上传文件
2. 浏览器录音/读取文件
3. 音频数据发送到后端
4. 后端获取 Token
5. 建立 WebSocket 连接
6. 发送音频数据到阿里云
7. 接收识别结果
8. 返回文本给前端

## 🔄 Token 管理机制

### 自动化流程

1. **首次调用**
   - 使用 AccessKey 获取 Token
   - 缓存 Token 和过期时间

2. **后续调用**
   - 检查缓存 Token 是否有效
   - 有效则直接使用
   - 无效则自动刷新

3. **刷新策略**
   - 提前 5 分钟刷新
   - 避免 Token 过期

### Token API

- 端点：`http://nls-meta.cn-shanghai.aliyuncs.com/`
- 方法：GET
- 签名：HMAC-SHA1
- 有效期：约 24 小时

## 🔍 故障排查

### 常见问题

1. **Token 获取失败**
   - 检查 AccessKey 配置
   - 检查网络连接
   - 查看后端日志

2. **TTS 转换失败**
   - 检查文本长度（<300字）
   - 检查音色名称
   - 检查参数范围

3. **ASR 识别失败**
   - 检查音频格式
   - 检查采样率（16000 Hz）
   - 检查音频质量

4. **麦克风权限被拒**
   - 使用 HTTPS 协议
   - 检查浏览器设置
   - 重新加载页面
