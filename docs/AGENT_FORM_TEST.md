# 智能体编辑页面功能测试指南

## 测试环境准备

1. 确保后端服务运行在 `http://localhost:3001`
2. 确保前端服务运行在 `http://localhost:5173` (或你的开发服务器)
3. 确保已登录并获得有效的 token

## 测试用例

### 1. 基本信息编辑

**测试步骤:**
1. 打开智能体编辑页面
2. 填写以下信息：
   - 名称: "测试智能体"
   - 描述: "这是一个测试智能体"

**预期结果:**
- 左侧编辑栏宽度固定为 500px
- 右侧预览面板实时显示输入的名称和描述
- 预览面板中的信息与左侧输入框同步更新

---

### 2. 系统提示词优化

**测试步骤:**
1. 在"系统提示词"区域输入: "你是一个友好的助手"
2. 点击"✨ 优化"按钮

**预期结果:**
- 按钮显示加载状态
- 优化完成后提示词被更新
- 右侧预览面板不显示提示词内容（仅显示基本信息）

---

### 3. 开场白配置

**测试步骤:**
1. 勾选"开场白"复选框
2. 输入开场白文本: "你好，欢迎使用我的服务"
3. 点击"+ 添加问题"添加快捷问题
4. 输入快捷问题: "你能做什么？"

**预期结果:**
- 开场白区域展开显示输入框
- 快捷问题可以添加和删除
- 右侧预览面板显示开场白内容
- 最多可添加 10 个快捷问题

---

### 4. 知识库配置

**测试步骤:**
1. 勾选"启用知识库"复选框
2. 从列表中选择一个或多个知识库

**预期结果:**
- 知识库选择区域展开
- 可以多选知识库
- 选中的知识库在保存时被记录
- 取消勾选"启用知识库"后，知识库选择区域隐藏

---

### 5. 功能开关

**测试步骤:**
1. 勾选各个功能复选框：
   - 对话开启白
   - 下一步建议
   - 文字转语音
   - 语音转文字

**预期结果:**
- 每个功能可独立开启/关闭
- 右侧预览面板显示启用的功能标签
- 勾选"文字转语音"后，TTS 配置区域出现

---

### 6. 文字转语音配置 ⭐ 重点测试

**测试步骤:**

#### 6.1 音色选择
1. 勾选"文字转语音"功能
2. 打开"音色"下拉菜单

**预期结果:**
- 下拉菜单显示 10 个常用音色：
  - Cherry - 标准女声
  - Serena - 温柔女声
  - Chelsie - 活力女声
  - Momo - 可爱女声
  - Vivian - 知性女声
  - Moon - 成熟女声
  - Maia - 甜美女声
  - Kai - 标准男声
  - Nofish - 磁性男声
  - Bella - 活泼女声

#### 6.2 音色预览 ⭐
1. 从下拉菜单选择一个音色（如 "Cherry"）
2. 点击"🔊 预览音色"按钮

**预期结果:**
- 按钮显示加载状态
- 后端调用 `/api/tts` 接口
- 返回音频数据并自动播放
- 播放预览文本: "这是音色预览，请听一下这个声音是否满意。"
- 使用选中的语速进行播放

#### 6.3 语速调节
1. 拖动"语速"滑块
2. 改变语速值（如从 150 改为 100）
3. 再次点击"🔊 预览音色"

**预期结果:**
- 滑块显示当前语速值
- 语速范围: 50-200
- 预览时使用新的语速值
- 语速越低，播放越慢；语速越高，播放越快

#### 6.4 自动播放
1. 勾选"自动播放"复选框

**预期结果:**
- 复选框状态被记录
- 保存时将 autoPlay 字段设置为 true

---

### 7. 内容审查

**测试步骤:**
1. 勾选"内容审查"复选框
2. 在文本框中输入敏感词（每行一个）：
   ```
   敏感词1
   敏感词2
   敏感词3
   ```
3. 点击"导入敏感词"按钮

**预期结果:**
- 内容审查区域展开
- 敏感词被正确解析和保存
- 导入后敏感词列表被更新

---

### 8. 右侧预览面板

**测试步骤:**
1. 在左侧编辑各个字段
2. 观察右侧预览面板的实时更新

**预期结果:**
- 预览面板显示以下信息：
  - 名称（实时更新）
  - 描述（实时更新）
  - 开场白（如果启用）
  - 启用的功能标签
- 预览面板下方是对话测试区域
- 可以输入消息进行测试

---

### 9. 对话测试

**测试步骤:**
1. 在右侧预览面板的输入框输入: "你好"
2. 按 Enter 或点击发送按钮

**预期结果:**
- 消息显示在对话框中
- 用户消息显示在右侧（蓝色气泡）
- 等待后端响应
- 助手消息显示在左侧（灰色气泡）
- 可以继续对话

---

### 10. 保存智能体

**测试步骤:**
1. 填写所有必填字段（至少填写名称）
2. 点击"保存"按钮

**预期结果:**
- 按钮显示"保存中..."状态
- 发送 POST 请求到 `/api/agent/create`（新建）或 PUT 请求到 `/api/agent/:id`（编辑）
- 请求体包含所有字段，包括新增的 `enableKnowledgeBase` 和 `ttsConfig`
- 保存成功后跳转到 `/agent/my-agents` 页面

---

### 11. 编辑已有智能体

**测试步骤:**
1. 从智能体列表中选择一个已有的智能体
2. 点击编辑按钮
3. 修改任意字段
4. 点击保存

**预期结果:**
- 页面标题显示"编辑智能体"
- 所有字段被正确加载
- 新增字段（enableKnowledgeBase、ttsConfig）被正确加载
- 修改后保存成功

---

## 数据验证

### 请求体验证

保存时，请求体应包含以下结构：

```json
{
  "name": "测试智能体",
  "description": "这是一个测试智能体",
  "model": "deepseek-chat",
  "personality": "你是一个友好的助手",
  "enableKnowledgeBase": true,
  "knowledgeBaseIds": ["kb_id_1", "kb_id_2"],
  "greeting": {
    "enabled": true,
    "text": "你好，欢迎使用我的服务",
    "quickQuestions": ["你能做什么？"]
  },
  "features": {
    "conversationOperator": true,
    "nextQuestionSuggestion": false,
    "textToSpeech": true,
    "speechToText": false,
    "contentModeration": true
  },
  "ttsConfig": {
    "voice": "Cherry",
    "speechRate": 150,
    "autoPlay": false
  },
  "sensitiveWords": ["敏感词1", "敏感词2"]
}
```

### 响应体验证

创建/更新成功时，响应应包含：

```json
{
  "code": 0,
  "data": {
    "agent": {
      "id": "agent_id",
      "name": "测试智能体",
      "enableKnowledgeBase": true,
      "knowledgeBaseIds": ["kb_id_1", "kb_id_2"],
      "ttsConfig": {
        "voice": "Cherry",
        "speechRate": 150,
        "autoPlay": false
      },
      ...
    }
  },
  "message": "智能体创建成功"
}
```

## 浏览器控制台检查

打开浏览器开发者工具 (F12)，检查：

1. **Network 标签:**
   - 验证 API 请求 URL 正确
   - 验证请求方法正确 (POST/PUT)
   - 验证请求头包含 Authorization token
   - 验证响应状态码为 200 或 201

2. **Console 标签:**
   - 检查是否有错误信息
   - 验证日志输出正确

3. **Application 标签:**
   - 验证 localStorage 中的 token 存在

## 常见问题排查

### 问题 1: 音色预览无声音
- 检查浏览器音量是否静音
- 检查后端 TTS 服务是否正常运行
- 检查网络请求是否成功 (Network 标签)
- 检查浏览器控制台是否有错误

### 问题 2: 保存失败
- 检查是否填写了必填字段（名称）
- 检查网络连接
- 检查后端服务是否运行
- 查看浏览器控制台错误信息

### 问题 3: 预览面板不更新
- 刷新页面
- 检查浏览器控制台是否有 Vue 错误
- 检查字段绑定是否正确
